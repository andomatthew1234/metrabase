# 🌌 Metrabase
**High-performance media capture suite for Windows.**

Metrabase is a sleek, dark-mode-ready Electron application designed to download YouTube Videos easily and quickly, with no ads, directly from a desktop app for free.

## ✨ Features
* 🚀 **Queue System:** Add multiple links and let Metrabase handle the rest. Metrabase will automatically start the next video in the queue when the first one is finished. Set and forget.
* 🌓 **Dark Mode:** Easy on the eyes for those late-night sessions.
* 📊 **Live History:** Automatically logs your downloads to `history.csv` file.
* ⚡ **Portable:** Built with performance in mind.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom #2e14a3 Branding)
* **Backend:** Node.js, Electron
* **Engine:** Python + yt-dlp

## 🚀 Let's get started
1. Select a Metrabase release in the sidebar of this GitHub page (in the releases area!)
2. Read and follow the instructions to install Metrabase.
3. Launch the app and enjoy the worlds best video downloader app!
